# 新机器最小执行方案（ROS 2 Humble）

原 Noetic/catkin 部署步骤已经停用。完整且可复现的依赖、Docker、Livox SDK2、
构建、测试、launch 和真机网络说明统一维护在：

- [ROS 2 Humble 新机安装与构建](ROS2_HUMBLE_INSTALL.md)
- [ROS 2 迁移状态、API 映射与风险](ROS2_MIGRATION_STATUS.md)

容器内最短流程：

```bash
source /opt/ros/humble/setup.bash
cd /workspace
rosdep install --from-paths src --ignore-src --rosdistro humble -r -y
colcon build --symlink-install --executor sequential
source /workspace/install/setup.bash
colcon test --executor sequential
colcon test-result --verbose
```

预期发现 18 个 package，完整验收基线为 116 tests、0 errors、0 failures。
编译通过不代表实车安全验收通过；首次运行必须遵守[真机操作手册](OPERATIONS.md)。
